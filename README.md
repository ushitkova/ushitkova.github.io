# Meri Ushitkova — UX/UI portfolio

A responsive React portfolio focused on concise, evidence-led UX case studies.

## Local development

```bash
npm install
npm run dev
```

Run `npm run build` to create the production site in `dist/`.

## Publishing

Pushing to `main` builds and deploys the portfolio with GitHub Pages. In the
repository settings, set **Pages → Source** to **GitHub Actions** once.
